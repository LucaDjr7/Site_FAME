# FAME glossary

## Euronext

Euronext is the main pan-European stock exchange, operating several venues (including Paris, Amsterdam, Brussels, Lisbon, Dublin, Milan, Oslo). It is the reference market scope for FAME's work. Current work focuses on the Oslo and Lisbon universes.

## Sentiment analysis

A set of natural language processing (NLP) techniques used to estimate the tone — positive, negative, or neutral — or the orientation of a text. At FAME, it is applied to financial news to derive signals.

## Sentiment signal

A quantitative indicator derived from the sentiment of financial news, meant to be related to market behaviour. We start from the news, estimate its tone with NLP methods, then aggregate that information into a usable signal.

## NLP (natural language processing)

A set of computational methods for analysing and exploiting natural-language text — for example to classify, summarise, or estimate the sentiment of a document.

## LLM (large language model)

An LLM is an artificial-intelligence model trained on very large amounts of text, able to understand and generate natural language. At FAME, this kind of model can be used to analyse financial news and estimate its sentiment. The site's assistant, Astra, is itself built on an LLM.

## Machine learning

A family of methods by which a model learns patterns from data rather than from hand-written rules. It is one of FAME's two methodological pillars, alongside finance.

## Backtest

A retrospective evaluation of a signal or strategy over historical data, to measure its performance before any real use.

## Nextwise

A partner platform of FAME, used to run the project's experiments.

## Research subject (on the platform)

A sheet describing a line of work (context, method, results, tasks, files). Visitors read public subjects; members create and edit them.

## Cross-cutting (transversal) subject

A subject marked as concerning both labs (broader visibility across the two labs).

## Confidential subject

A subject reserved for members: never visible to visitors, neither via the assistant nor via public navigation.

## Internship (at FAME)

The most common entry point into the project: most members start with an internship, during which they advance the project on subjects that interest them.
