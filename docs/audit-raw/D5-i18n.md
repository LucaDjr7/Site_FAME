### ⚪ F-DEAD-01 — `tasks.history` jamais appelée par `t()`

- **Fichier** : `messages/en.json` (+ `fr.json`) — namespace `tasks`, clé `history`
- **Impact** : clé inutilisée, entretien superflu
- **Reproduction** : `grep -rn "t('history')" src/` → aucun résultat (seul `src/lib/constants.ts` contient `'history'` mais comme valeur d'un tableau de constantes, pas comme clé i18n)
- **Fix suggéré** : supprimer `tasks.history` des deux JSON, ou l'utiliser dans `TaskModal.tsx` si un onglet historique est prévu

### 🟡 F-DEAD-06 — `common.*` : 12 clés sur 14 ne sont jamais référencées

## Section 4 — Chaînes hardcodées (🟠 user-facing)

### 🟠 F-HC-01 — Kickers "FAME / {labLabel}" hardcodés dans 4 composants

- **Fichiers** :
  - `src/components/publications/PublicationList.tsx:248`
  - `src/components/data/DataExplorer.tsx:282`
  - `src/components/prompts/PromptLibrary.tsx:147`
  - `src/components/team/MemberGrid.tsx:131`
- **Texte** : `FAME / {labLabel}` où `labLabel = lab === 'paris' ? 'Paris' : 'Montréal'`
- **Impact** : Le kicker de section visible par tous les utilisateurs est en dur dans le code. Pas traductible, pas cohérent avec les namespaces `tasks.kicker` / `lab.kicker` / `propose.kicker` (ces derniers passent bien par `t('kicker')`).
- **Reproduction** : voir directement `PublicationList.tsx:248`, `DataExplorer.tsx:282`, `PromptLibrary.tsx:147`, `MemberGrid.tsx:131`
- **Fix suggéré** : ajouter `publications.kicker`, `data.kicker`, `prompts.kicker`, `team.kicker` dans EN et FR (ex. `"FAME / {lab}"` avec interpolation), et les consommer via `t('kicker', { lab: t('nav.labParis') })`
